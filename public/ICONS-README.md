# PWA Icons

You need to create two icon files for the Progressive Web App:

- `icon-192.png` - 192x192 pixels
- `icon-512.png` - 512x512 pixels

## Quick Icon Generation

You can use any of these free tools:

1. **Favicon.io** (https://favicon.io)
   - Text to icon generator
   - Upload an image
   - Choose emoji

2. **RealFaviconGenerator** (https://realfavicongenerator.net)
   - More comprehensive
   - Generates all sizes

## Design Suggestions

For a workout/fitness app, consider:
- Dumbbell icon
- Barbell icon
- Simple "W" letter on dark background
- Muscle/strength symbol

## Requirements

- Square aspect ratio (same width and height)
- Simple, recognizable at small sizes
- Dark background (#0a0a0a) to match app theme
- High contrast icon/text
